# HabitTracker

Application created with angular and tailwind.


A simple Angular application to help you track, rate, and analyze your daily habits.

## Features

- **Track Habits:** Log daily habits and assign their severity or importance.  
- **Rate Daily Performance:** For each habit, assign a performance grade (1–5) to see how well you adhered to your routines.  
- **Notes & Insights:** Add notes for each day to record what helped you succeed or what led to lapses.  
- **Filled Reports:** Review completed reports with detailed habit grades and daily performance scores (1–10).  
- **Daily Performance Graph:** Visualize your habit adherence over time using a bar chart.  
- **Light/Dark Theme:** Switch between light and dark modes.  
- **Responsive Design:** Optimized for both mobile and desktop screens.
